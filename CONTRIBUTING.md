# Contributing / Contribuir

**English:** Start with the [development guide](docs/development.en.md). Use a separate branch and synthetic fixtures. Include what changed, why, the relevant test results and any deployment or migration requirements in your pull request. Never submit credentials, real conversations, personal names, account details, database snapshots or private infrastructure references. Keep both documentation languages synchronized.

**Español:** Empieza por la [guía de desarrollo](docs/development.es.md). Usa una rama separada y datos ficticios. Explica en el pull request qué cambia, por qué, qué pruebas pasan y si requiere despliegue o migraciones. No incluyas credenciales, conversaciones reales, nombres personales, cuentas, copias de bases ni referencias de infraestructura privada. Mantén sincronizada la documentación en ambos idiomas.
